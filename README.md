# zpg

`zpg` is a lightweight, high-performance PostgreSQL client written in pure Zig, created as a fast, low-footprint alternative to heavy database management tools. It packs both a desktop graphical interface (GUI) and an interactive terminal mode (TUI) into a single binary, delivering instant startup times and minimal RAM usage.

> **Status:** Active development. This project is in an experimental stage and is currently not ready for production use.
